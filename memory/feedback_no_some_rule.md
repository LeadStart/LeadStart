On 2026-09-27 I said "some" TuBe reports have a location-page audit. The owner: "We can't have a 'some' rule. What do you mean 'Some'…?"

**Why:**
- One template goes to every contact, so a line that's true for only part of the list is a false claim to the rest.
- A vague "some" also hides what the owner needs to decide.

**How to apply:**
- Before proposing a copy line built on per-prospect data, measure its coverage across the WHOLE list (e.g. read every report, as in scratchpad p71) and state exact counts plus the reason for each gap.
- Only lines true for 100% of recipients go in the shared template. A per-segment version is also a "some" rule, so don't offer it as the fix.
- Watch values that are present but degenerate: 0 issues, failed scans showing "2 checks", 0/100 scores. They break a line even when the field is filled.
